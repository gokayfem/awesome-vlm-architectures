# VLM architecture review — October 27, 2026

This review updates the August 1, 2026 catalog at commit `74897b3`: **155 → 200 architecture entries**, with **45 additions**, historical gap filling, and later releases folded into existing families. The cutoff is October 27, 2026 in Europe/Istanbul.

## Scope and evidence

The catalog follows [CONTRIBUTING.md](CONTRIBUTING.md): include a distinct architecture, alignment, training, or data contribution with a primary technical source. Search coverage included official model releases, repositories, model cards, technical reports, and arXiv publication histories across general VLMs, omni-modal models, encoders, document/OCR systems, visual agents, scientific models, and unified understanding/generation.

Dates below distinguish announcements, actual weight releases, paper submissions, and documented upload fallbacks. A later paper revision or repository creation date is not automatically a release. Historical public/private repository visibility cannot be reconstructed from Git timestamps alone. The entries using upload evidence and the unresolved Step 5 and Intern-S1 dates should be treated accordingly. This is a curated architecture survey, not a claim to enumerate every fine-tune, size, API alias, or undisclosed proprietary system.

Each new entry has a summary, primary-source badges, author/team attribution, release metadata, an architecture/training/data explanation, and an explicit figure decision. When corpus details are unavailable, the entry says so. The [machine-readable source ledger](data/reviews/2026-10-27.json) records date evidence, reviewed card hashes and available model revisions; the [figure manifest](assets/architectures/manifest.json) records image provenance, PDF page, crop, hashes, and review date.

## Availability and source caveats

- **Step 5 Preview:** October 15 is the dated architecture disclosure, not a verified first API release. Earlier checkpoint activity exists. Its introduction mentions video, while its input table lists text/image; the README preserves that discrepancy.
- **Intern-S1:** August 21, 2025 is the report fallback. An earlier public launch date was not established from the sources used here; the date is not asserted as the first weight availability.
- **Muse Glimmer, Ling-3.0-flash-VL, GLM-5.3-Flash:** upload-based dates are explicitly labeled. An initial or private repository commit alone does not establish public availability.
- **Nemotron 3.5 Super VL:** official artifacts disagree on the C-RADIO version label. The entry uses the supported family name and avoids choosing a version without resolving the discrepancy.
- **Audio-Visual Flamingo:** the paper includes a speech-output path, but the released checkpoint produces text. **OmniVinci** illustrates an external frozen TTS component. Captions explain these limits.
- **Qwen3.5-Omni / Qwen3.8-Omni-Flash:** papers and hosted systems are documented; supporting code is not an open-weight release.
- **Emu3.5:** public autoregressive weights are distinguished from the report’s DiDA acceleration, whose release remains pending.
- **Holo4:** 35B-A3B and 27B have different licensing terms. **Muse Spark Open** and **Moondream 3** use custom licenses; “open weights” is not treated as synonymous with permissive open source.

## Watchlist and exclusions

- **Mistral Large 4:** the October 6 preview announced a later weight release planned for October 31, after this cutoff. It is not counted as a released open-weight architecture here. Recheck the [official announcement](https://mistral.ai/news/mistral-large-4/) and [model page](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B) after publication.
- **Nex family variants:** model-card checkpoint derivatives without a sufficiently distinct disclosed architecture were not duplicated. Text-only variants are outside VLM scope.
- **Ovis, SmolVLM2, InternVL3.5 and other existing families:** retained rather than duplicated under new checkpoint names.
- Proprietary API updates without enough architecture disclosure, pure text LLMs, quantizations, adapters, and generation-only releases are outside the entry criteria. Benchmark rank or a recent upload alone is not an architectural contribution.

## Reproduction

Run `python scripts/build_release_timeline.py` and `python scripts/embed_architecture_figures.py` after editing panels or the manifest. Their `--check` modes verify timeline coverage, exact figure content, and complete per-panel figure decisions. The extractor accepts official PDF URLs, reviewed table crops, official image sources, and supplemental family figures. New-image hashes and PDF crop coordinates are stored in the manifest; temporary full PDFs are not committed.
